# PweB · Home

Персональный веб-хаб для учёбы, проектов, заметок и повседневных инструментов.

**Сайт:** https://belovvlad.github.io/  
**Репозиторий:** https://github.com/BelovVlad/belovvlad.github.io

`PweB/Home` — самостоятельный Git-репозиторий. Другие приложения остаются отдельными проектами и открываются по URL. Хаб не использует iframe и не копирует учебные материалы.

## Запуск

Рабочий сайт не требует сборки, сервера приложений или зависимостей. Для локального просмотра нужен любой статический HTTP-сервер; не открывайте `index.html` через `file://`, поскольку ES-модули требуют HTTP.

С Node.js 22+:

```sh
npm run dev
```

Откройте http://127.0.0.1:43871. Зависимости нужны только для браузерных тестов.

## Использование

- Добавляйте ссылки кнопкой «Добавить ресурс», меняйте их через меню `…`.
- Пустой URL создаёт заготовку. Для второго семестра адрес намеренно не выдуман.
- Звезда закрепляет карточку в избранном. Через меню карточки можно менять порядок внутри раздела.
- Чтобы переместить карточку в другой раздел, измените её поле «Раздел».
- Разделы добавляются кнопкой `+` рядом с навигацией, изменяются в настройках. Удалить можно только пустой раздел.
- Поиск находит названия, описания, адреса и разделы, включая пустые. `Ctrl+K` / `⌘K` переводит фокус в поиск.
- Переключайте сетку/список и тему. Доступна тема системы.
- Небольшой список «На сегодня» сохраняет задачи и их выполнение; автоматического сброса в полночь нет.

## Данные и резервные копии

Коллекция, задачи и настройки сохраняются в `localStorage` под отдельным ключом `pweb.home.v1`. Между устройствами автоматической синхронизации нет. В настройках доступны экспорт и импорт JSON. Импорт проверяет формат, ссылки, уникальность ID и наличие разделов, затем запрашивает подтверждение полной замены коллекции. Сначала экспортируйте текущую конфигурацию, если хотите её сохранить.

Если сохранённые данные повреждены, приложение показывает исходную коллекцию и не перезаписывает повреждённую запись. Изменения до импорта корректной копии остаются в памяти; их можно экспортировать. При переполнении хранилища или запрете записи интерфейс также явно сообщает, что изменения не сохранены. Для сохранения данных избегайте приватного режима и очистки данных сайта без резервной копии.

Все сайты `belovvlad.github.io` имеют общий origin, поэтому хаб использует собственный ключ. Корневого Service Worker здесь нет: он не перехватывает запросы учебного сайта и DarkNotes. Установка PWA и офлайн-кэширование не реализованы.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка страницы и доступные диалоги |
| `styles.css` | Адаптивная сетка, темы и оформление |
| `config.js` | Начальные разделы, реальные ссылки и заготовки |
| `model.js` | Проверка JSON, поиск и порядок ресурсов |
| `app.js` | Интерфейс, настройки, хранилище, задачи |
| `icons.js` | Локальные SVG-иконки без CDN |
| `assets/eva-hero.webp` | Исходный баннер с основного сайта, без генеративных изменений |
| `scripts/serve.mjs` | Локальный статический сервер |
| `scripts/package.mjs` | Подготовка только публичных файлов в `_site` |
| `tests/` | Проверки модели и браузерных сценариев |

Визуальный ориентир — предоставленный пользователем референс персонального хаба: верхняя панель поиска, избранные карточки, разделы и небольшие виджеты. Палитра взята из CSS готового учебного сайта: фон `#080d12`, панели `#0e151c`, текст `#f1ede7`, кремовый `#ead4b7`, тёплый `#b78b62`, акцент `#d64c50`, границы `#25303a`. Баннер `nsu-eva-hero.webp` взят по просьбе владельца из [основного проекта](https://github.com/BelovVlad/NSU_FP_Y4_S1/tree/main/docs/assets); исходный файл 2116 × 743 достаточно широкий и не расширялся. Баннер кадрируется через CSS, исходник сохранён целиком. Внешние шрифты и сторонние трекеры не используются.

Для новых виджетов добавьте отдельный модуль и секцию в `.widgets`. Для расширения формата данных обновите `validateConfig` и предусмотрите чтение предыдущей версии. Изменение `config.js` задаёт начальную коллекцию для новых браузеров; уже сохранённую коллекцию оно не перезаписывает.

## Проверки

```sh
npm ci
npm test
npx playwright install chromium
npm run test:e2e
```

Браузерные проверки покрывают CRUD, разделы, порядок, избранное, сохранение, поиск, JSON, защиту повреждённых данных, задачи, темы и размеры 375/820/1024/1440 px. Для установленного браузера можно передать `PWEB_BROWSER` — полный путь к исполняемому файлу Chromium. Реальные iPhone/iPad не заменяются эмуляцией.

## GitHub Pages

Репозиторий пользователя называется `belovvlad.github.io`, поэтому публикация открывается в корне домена. В Settings → Pages выбран источник **GitHub Actions**. Workflow `.github/workflows/pages.yml` при push в `main` запускает проверки, подготавливает `_site` и публикует статический артефакт. PR запускает проверки без публикации. После локальных изменений:

```sh
git add .
git commit -m "Update Home"
git push
```

Существующие репозитории и адреса `/NSU_FP_Y4_S1/` и `/DarkNotes/` остаются самостоятельными. При размещении в другом подкаталоге относительные пути ресурсов также работают.
